# Installing MWOW User Tools (IDL)

No special installation is required. The IDL script is self-contained
and uses only built-in IDL functions.

## Usage

Open `examples/mwow_example_scripts.pro` in IDL. The script contains
internal documentation explaining how to access MWOW v0.2 data,
extract point time series, match ship tracks, and select regions.

Edit the `data_path` variable at the top to point to your MWOW data
directory, then run each section.

## MWOW v0.2 data products

See `INSTALL_python.md` for a description of the four available data
products and download instructions. You will need a free NASA Earthdata
Login account at <https://urs.earthdata.nasa.gov/>.
